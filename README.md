# 🧠 Mental Health Sentiment Correlation

![Mental Health Sentiment Correlation Dashboard](./mental%20dashboard.PNG)

## 📌 Project Overview

**Mental Health Sentiment Correlation** is a data analytics project focused on analyzing large-scale public social media data to explore sentiment patterns and their relationship with mental-health-related indicators.

The project examines **Positive, Neutral, and Negative sentiments** across different mental health labels and over time. The analysis combines data preprocessing, sentiment analysis, feature extraction, and interactive visualization to identify meaningful patterns in the data.

This project was completed as part of my **Dynamix Networks Internship**.

---

## 🎯 Objective

The main objective of this project is to analyze social media sentiment patterns and explore how they correlate with mental-health-related trends such as **stress, anxiety, and depression**.

The project aims to:

- Analyze sentiment patterns in social media posts
- Compare sentiment across different mental health labels
- Identify changes in sentiment over time
- Analyze linguistic features within the posts
- Present the findings through an interactive dashboard

---

## 🔧 Tasks Performed

### 1. Data Cleaning & Preprocessing

The dataset was cleaned and prepared for analysis by organizing the available data and preparing relevant fields for sentiment analysis and visualization.

### 2. Sentiment Analysis

Social media posts were analyzed and categorized into three sentiment groups:

- Positive
- Neutral
- Negative

Sentiment counts, percentages, and scores were used for further analysis.

### 3. Feature Extraction

Relevant linguistic and sentiment-related features were extracted from the dataset.

The analysis includes features such as:

- Sentiment Score
- Sentiment Category
- Exclamation Mark Usage
- Mental Health Label

### 4. Visualization Dashboard

An interactive dashboard was created using **Microsoft Power BI** to present the analysis in a clear and user-friendly format.

---

## 📊 Dashboard Highlights

The Power BI dashboard includes:

- **Total Posts**
- **Negative Sentiment %**
- **Positive Sentiment %**
- **Sentiment Distribution**
- **Sentiment Count**
- **Average Sentiment Score by Mental Health Label**
- **Average Exclamation Usage by Mental Health Label**
- **Sentiment Trend Over Time**

### 🎛️ Interactive Filters

The dashboard allows users to explore the data using filters for:

- Year
- Sentiment
- Mental Health Label

---

## 🔍 Key Insights

The analysis provides insights into how sentiment and linguistic patterns vary across different mental health labels.

Some of the major observations include:

- Positive sentiment forms the largest sentiment category in the analyzed dataset.
- Negative and neutral sentiments also represent significant portions of the posts.
- Average sentiment scores vary across different mental health labels.
- Exclamation mark usage differs between mental health labels, providing an additional linguistic feature for comparison.
- Sentiment patterns change over time, allowing users to explore trends across different years.
